# 📊 Sistema de Gestão Comercial

Sistema Full Stack desenvolvido para gerenciamento de clientes, produtos e vendas, utilizando **React**, **Node.js**, **Express** e **MySQL**.

O projeto foi desenvolvido com foco em aprendizado de desenvolvimento Full Stack, integração entre frontend e backend, consumo de APIs REST e publicação em ambiente de produção.

# ✨ Funcionalidades

## 🔐 Autenticação

* Tela de login
* Navegação entre páginas

## 👥 Clientes

* Cadastro de clientes
* Pesquisa por nome
* Edição de clientes
* Exclusão de clientes

## 📦 Produtos

* Cadastro de produtos
* Atualização de informações
* Exclusão de produtos
* Controle de estoque

## 🛒 Vendas

* Cadastro de vendas
* Gerenciamento de pedidos

## 📊 Dashboard

* Total de clientes
* Total de produtos
* Total de vendas
* Faturamento
* Produtos com estoque baixo
* Ranking dos produtos mais vendidos
* Gráfico de vendas mensais
